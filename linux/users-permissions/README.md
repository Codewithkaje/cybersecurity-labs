# Linux Users and Permissions

This section documents my practical study of Linux users, groups,
file ownership, permissions, and privilege boundaries.

## Topics

- Users and UIDs
- Groups and GIDs
- File ownership
- Read, write, and execute permissions
- `chmod`
- `chown`
- `sudo`
- SUID
- Linux capabilities

## Goal

Understand what a low-privileged Linux user can access, what they
cannot access, and how Linux enforces those boundaries.
