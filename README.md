## Philosophy

I focus on understanding why vulnerabilities and security weaknesses work rather than simply following exploitation commands.

Each project aims to document:

1. What was investigated
2. How it was discovered
3. Why it works
4. How it can be reproduced in a controlled environment
5. How it can be mitigated
